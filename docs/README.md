# Documentation

**[STATUS.md](STATUS.md) is the orientation page.** It says what is built,
which documents are authoritative, and where the code departs from them.

Global documentation — system-wide truth that affects more than one surface.
Implementation detail specific to a single surface lives in that surface's own
`docs/` folder instead.

| Folder | Holds |
|---|---|
| `project/` | The locked requirements blueprint and the official problem statement |
| `architecture/` | System boundaries, responsibility maps, and the low-level design |
| `design/` | UI and interaction briefs, visual direction (used once S6/S7 begins) |
| `history/` | Past decisions, investigations, and context future contributors need |
| `tasks/` | Current work packets and acceptance criteria |
| `reviews/` | Stress tests, critique packets, and readiness reviews |

History belongs closest to the thing it explains.
