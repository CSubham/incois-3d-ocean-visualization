# Ingestion (S2)

The Data Ingestion stage: accept, read and parse the supported input formats,
and write canonical datasets plus catalogue rows.

Owns 11 SRS requirements — DIR-001 to DIR-007, ING-001, ING-002, STD-001, and
the ingestion aspect of EXT-001. See `../docs/architecture/` for the stage
design and `../data/README.md` for the sample data this stage consumes.

Not yet implemented.
